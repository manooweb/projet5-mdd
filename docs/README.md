# Documentation et livrables

Ce dossier regroupe la documentation générée par le projet et les sources des livrables destinés à la soutenance OpenClassrooms.

Les documentations liées directement au code conservent leur langue et leur rôle technique :

- [`javadoc/`](javadoc/): conventions et Javadoc générée depuis le backend Java.
- [`reports/coverage/`](reports/coverage/README.md): rapports de couverture générés par JaCoCo, Vitest et Cypress.

Les annexes de soutenance sont rédigées en français dans [`livrables/`](livrables/README.md). Elles constituent les sources Markdown consultables dans Git. Elles pourront ensuite être intégrées et mises en forme dans le document Writer final avant son export en PDF.

Les noms des fichiers de livrables sont en français sans accents afin de conserver des chemins Git simples et stables.
