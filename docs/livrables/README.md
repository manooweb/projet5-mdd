# Sources des livrables de soutenance

Ce dossier accueillera les sources Markdown en français des annexes demandées pour le projet MDD :

- analyse des besoins frontend ;
- définition des données ;
- rapport de tests et de couverture ;
- rapport de revue technique ;
- FAQ utilisateur ;
- journal de supervision IA ;
- captures d'écran utilisées pour illustrer ces documents.

Les fichiers finaux destinés au dépôt sur la plateforme OpenClassrooms seront regroupés dans `deliverables/` après la finalisation du document Writer et des exports PDF.
